  MODKEY = Super (Win key)

── WINDOWS ─────────────────────────────────────────────────────
  Mod + Shift + Enter   Open terminal (kitty)
  Mod + p               dmenu launcher
  Mod + s               Settings menu (display / audio / bt / net)
  Mod + Shift + c       Kill focused window
  Mod + j / k           Focus next / previous window
  Mod + Shift + j / k   Move window down / up in stack
  Mod + Return          Zoom (swap with master)
  Mod + Shift + Space   Toggle floating
  Mod + drag            Move floating window
  Mod + right-click     Resize floating window

── LAYOUTS ─────────────────────────────────────────────────────
  Mod + t               []=  Tile (default, 8px gaps)
  Mod + f               ><>  Float
  Mod + m               [M]  Monocle (fullscreen stack)
  Mod + Space           Toggle last two layouts
  Mod + h / l           Shrink / grow master area
  Mod + i / d           Inc / dec number of masters

── TAGS (workspaces) ───────────────────────────────────────────
  Mod + 1-9             Switch to tag
  Mod + Shift + 1-9     Move window to tag
  Mod + Ctrl + 1-9      Toggle tag view
  Mod + 0               Show all tags
  Mod + Tab             Toggle previous tag
  Mod + , / .           Focus prev / next monitor
  Mod + Shift + , / .   Move window to other monitor

── BAR ─────────────────────────────────────────────────────────
  Mod + b               Toggle bar on/off
  Right side            󰻠 CPU%  󰍛 RAM  battery  󰕾 vol%  󰥔 time
  Systray icons         wifi (nm-applet)  bluetooth  audio (pasystray)

── LAPTOP FN KEYS ──────────────────────────────────────────────
  XF86AudioRaiseVolume  Volume +5%   (wpctl)
  XF86AudioLowerVolume  Volume -5%
  XF86AudioMute         Toggle mute
  XF86BrightnessUp      Brightness +10%  (brightnessctl)
  XF86BrightnessDown    Brightness -10%
  Print                 Screenshot → ~/Pictures/scrot/

── SETTINGS MENU (Mod + s) ─────────────────────────────────────
  Display (arandr)      drag monitors, set resolution/arrangement
  Audio (pavucontrol)   volume mixer, output device selector
  Bluetooth (blueman)   pair / connect devices
  Network               nm-connection-editor (VPN, saved networks)

── MULTIMONITOR (autorandr) ────────────────────────────────────
  First time:
    arandr                       position monitors visually
    autorandr --save docked      save HDMI layout
    autorandr --save mobile      save laptop-only layout
  After: plug/unplug HDMI auto-switches profiles
  Manual:  autorandr docked  /  autorandr mobile

── SESSION ─────────────────────────────────────────────────────
  Mod + Shift + q       Quit DWM

── PATCHES ─────────────────────────────────────────────────────
  systray       tray icons (right of bar)
  autostart     ~/.dwm/autostart.sh on launch
  alwayscenter  floating windows center on spawn
  attachbottom  new windows go to bottom of stack
  gaps          8px gaps in tile + monocle
  movestack     Mod+Shift+J/K reorders stack

── CATPPUCCIN MOCHA PALETTE ────────────────────────────────────
  Base       #1e1e2e   bar background
  Surface0   #313244   inactive border
  Text       #cdd6f4   normal text
  Mauve      #cba6f7   accent — selected bg + active border
  Base       #1e1e2e   text on selected

── KEY PATHS ───────────────────────────────────────────────────
  ~/nix-conf/dwm/config.def.h    keybinds, colors, rules
  ~/nix-conf/home.nix            user packages, kitty, dunst, autostart
  ~/nix-conf/configuration.nix   system — hardware, services, TLP
  ~/.dwm/autostart.sh            runs on DWM start (generated by HM)
  ~/nix-conf/cheatsheet/         this file
